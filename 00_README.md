# YT Channel Bulk Downloader: Spec Pack

How to use this pack (3 steps):

1. Create an empty folder `yt-bulk-downloader/` and copy all these files into a `docs/` folder inside it.
2. Copy `CLAUDE.md` to the project root. Also copy it as `AGENTS.md` (Codex/Windsurf) and `.cursorrules` (Cursor). Your AI editor reads it on every prompt.
3. Open `04_BUILD_PROMPTS.md` and paste prompts **one at a time**, in order. Do not move on until that step's "Done when" checks pass.

| File | Purpose |
|------|---------|
| 01_PRD.md | What to build and why |
| 02_TECH_SPEC.md | Exact APIs, types, yt-dlp commands, edge cases |
| 03_CLAUDE.md | Rules the AI editor must follow |
| 04_BUILD_PROMPTS.md | Step-by-step prompts (the workflow) |
| 05_TEST_CHECKLIST.md | How to verify it works |

Legal note: only download content you own or have permission to download. Downloading others' videos can violate YouTube's Terms of Service and copyright law.
